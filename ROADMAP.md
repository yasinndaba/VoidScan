# VoidScan Roadmap

VoidScan will evolve from a simple Python CLI into a modular reconnaissance and security assessment framework.

## Phase 1 — Foundation

* Project structure
* CLI
* Configuration
* Logging
* Target validation
* Testing

## Phase 2 — Reconnaissance

* Nmap
* Host discovery
* Subdomain enumeration
* Directory enumeration

## Phase 3 — Analysis

* Port analysis
* Service identification
* Findings
* Risk classification

## Phase 4 — Reporting

* Terminal reports
* JSON output
* HTML reports

## Phase 5 — Engineering

* Unit tests
* Integration tests
* CI/CD
* Dependency management
* Error handling

## Phase 6 — Release

* Documentation
* Demonstration lab
* Screenshots
* v1.0.0 release
